# 开源整合记录

ExamPilot 整合了此前的 Chaoxing AutoExam 工程，保留平台适配、AI Provider、状态/日志、模拟服务器、通知、macOS 脚本及测试。首次公开版本为 0.1.0a1。

原工作副本包含私人运行配置和已建立的会话，保持原样。公开项目使用全新 Git 历史，不复制 `.env`、config.yaml、session.json、数据库、日志、生成 plist、浏览器、虚拟环境或旧压缩包。

真实列表样本保留已观察的 HTML 结构，课程/考试/班级值替换为合成标识。公开验证文档保留方法和结论，原始账户/课程记录留在私有工作副本中。已完成状态的历史记录不是本程序提交的考试。

公开化新增：中文/英文 README、标准元数据与 GPL 许可声明、贡献/安全文档、CI、Issue/PR 模板、资源随 wheel 打包、初始化命令、运行目录选择和内容检查。`autoexam` 模块/命令兼容保留，主产品与命令为 ExamPilot / exampilot。

整合不会扩大真实平台验收结论：PC 作答页读取、保存、正式提交、手机送达、睡眠/实际重启仍待验证。
